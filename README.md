# MIMO Antenna Design Using ANSYS HFSS

## Project Overview

This project focuses on the design and electromagnetic simulation of a Multi-Input Multi-Output (MIMO) antenna using **ANSYS HFSS (High-Frequency Structure Simulator)**.

The antenna is modeled in ANSYS Electronics Desktop, and its electromagnetic performance is analyzed using simulation results.

## Software Used

- ANSYS Electronics Desktop
- ANSYS HFSS

## Project Details

- **Project Name:** Project_PESITM_26
- **Design Name:** HFSSDesign1
- **Solution Type:** Driven Terminal
- **Excitation:** Wave Ports
- **Number of Wave Ports:** 8

## Project Objectives

- Develop a MIMO antenna model using ANSYS HFSS.
- Configure excitation ports and boundary conditions.
- Perform electromagnetic simulations.
- Analyze antenna reflection characteristics.
- Study radiation patterns and antenna gain.

## How to Open the Project

1. Download or clone this repository.
2. Open ANSYS Electronics Desktop.
3. Select **File → Open**.
4. Browse to the HFSS project file.
5. Open the project and inspect the antenna design and simulation setup.

**Note:** Simulation results may require recomputation if the solution data is not included in the repository.
